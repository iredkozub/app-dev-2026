## Сложность функции calculate_discount

Временная сложность "calculate_discount(total)" — O(1).
Функция выполняет фиксированное число сравнений и арифметических операций независимо от значения "total".
В ней нет циклов или рекурсии, поэтому количество операций не растёт с размером входа.

Квадратичный риск O(n2) может возникнуть при поиске дубликатов двумя вложенными циклами по одному списку.
В таком случае каждый элемент сравнивается со всеми остальными элементами.
Использование "set" позволяет хранить уже встреченные значения и проверять наличие элемента в среднем за O(1).
Поэтому поиск дубликатов за один проход с "set" имеет в среднем сложность O(n).
