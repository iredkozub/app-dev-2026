## Анализ сложности алгоритмов

### Функция `calculate_discount(total)`

Временная сложность: **O(1)**.

Функция выполняет фиксированное число сравнений и арифметических операций независимо от значения `total`. В ней нет циклов или рекурсии, поэтому количество операций не растёт с размером входа.

### Квадратичный риск и оптимизация

Квадратичная сложность O(n²) может возникнуть при поиске дубликатов двумя вложенными циклами по одному списку. В таком случае каждый элемент сравнивается с остальными элементами. Использование `set` позволяет хранить уже встреченные значения и проверять наличие элемента в среднем за O(1). Поэтому поиск дубликатов за один проход с `set` имеет в среднем временную сложность **O(n)**.

### Valid Parentheses

Временная сложность: **O(n)**. Алгоритм обрабатывает каждый символ строки один раз.
Пространственная сложность: **O(n)**. В худшем случае стек хранит все открывающие скобки.

Стек выбран по принципу LIFO: последняя открытая скобка должна закрываться первой.
